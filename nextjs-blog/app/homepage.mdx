# Full Stack Blog

Welcome to the Full Stack Open part 14 blog application.

This homepage is rendered from a Markdown file using MDX, so the content
stays static while the rest of the app runs on the App Router.

## What is here

- Browse and search **blogs**
- Create an account and add blogs of your own
- Keep a personal **reading list** on your profile page
- Generate a personal **API token** for programmatic access

## Why server side rendering

Server components fetch data directly from the database without shipping
query logic to the browser. Forms submit through server actions, and pages
are revalidated automatically when the underlying data changes.
